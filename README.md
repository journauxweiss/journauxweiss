# Researching the Journaux de Charles Weiss

In this repository we include research done with the Journaux de Charles Weiss. 

Digitization of Besançon BM manuscript 1753-1754 is available at [Memoire Vive](https://memoirevive.besancon.fr/ark:/48565/wgmb04prsnj2/73f3c7b7-21cb-41a6-8dfc-3f34cfc90eec).
